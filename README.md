## 1. Overview

Compares three transfer-learning approaches on the **Oxford-IIIT Pet Dataset** (37 cat/dog breeds), using pre-trained **MobileNetV3-Small** (TorchVision) with the final layer adapted to 37 classes:

1. **Full Fine-Tuning** – train the whole network.
2. **Classifier-Head Training** – freeze the feature extractor, train only the classifier.
3. **Feature Extraction + SVM** – frozen backbone features + linear SVM (with StandardScaler).

All approaches use the same train/validation/test partitions.

## 2. Dataset

- [Oxford-IIIT Pet Dataset](https://www.robots.ox.ac.uk/~vgg/data/pets/), downloaded automatically to `data/` via `torchvision.datasets.OxfordIIITPet` (not committed to GitHub).
- Official **trainval** is split into train/validation with stratified sampling (seed and proportion set in `data_loader.py`).
- Official **test** split is used for final evaluation only.
- Validation set: checkpoint selection and SVM hyperparameter selection. Test set is never used for tuning.

## 6. Running

Run from the project root:

```bash
python full_finetuning.py            # Approach 1: saves best checkpoint (by validation)
python classifier_head.py            # Approach 2: frozen backbone, train classifier
python feature_extraction_svm.py     # Approach 3: features + StandardScaler + linear SVM
python evaluate.py                   # final comparison on the test set
```

## 7. Evaluation

Metrics: **Accuracy**, **Macro Precision**, **Macro Recall**, **F1-score** (over 37 classes).
Results are saved to `outputs/evaluation_results.csv` (one row per approach). Confusion matrices and sample correct/incorrect predictions can also be generated by the evaluation code.
